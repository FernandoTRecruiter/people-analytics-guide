Turnover Rate
Benchmark: 10–15% · Source: SHRM
Formula: Turnover Rate (%) = (Exits in period / Average HC) × 100
Avg HC = (HC start + HC end) / 2 · Source: fato_Historico (Event_Type = "Termination")
Excel — Turnover Rate
=CONT.SES(
    Historico[Tipo_Evento],  "Desligamento",
    Historico[Data_Evento],  ">="&DATA(ANO(HOJE()),1,1),
    Historico[Data_Evento],  "<="&HOJE()
) / ((HC_Inicio + HC_Final) / 2) * 100

Name cells: B2 = HC_Start (headcount Jan 1) and B3 = HC_End (current HC).

DAX — Power BI
Saídas no Período =
CALCULATE(COUNTROWS(fato_Historico), fato_Historico[Tipo_Evento] = "Desligamento")

HC Médio =
DIVIDE(
    CALCULATE(COUNTROWS(dim_Colaboradores), dim_Colaboradores[Status] = "Ativo",
              DATEADD(dim_dCalendario[Date], -12, MONTH))
    + CALCULATE(COUNTROWS(dim_Colaboradores), dim_Colaboradores[Status] = "Ativo"),
    2
)

Turnover Rate % = DIVIDE([Saídas no Período], [HC Médio], 0) * 100
SQL
WITH saidas AS (
    SELECT COUNT(*) AS total_saidas
    FROM fato_Historico
    WHERE Tipo_Evento = 'Termination'
      AND strftime('%Y', Data_Evento) = strftime('%Y','now')
),
hc AS (SELECT COUNT(*) AS hc FROM dim_Colaboradores WHERE Status = 'Ativo')
SELECT s.total_saidas,
       ROUND(s.total_saidas * 100.0 / h.hc, 2) AS turnover_rate_pct
FROM saidas s, hc h;
Python — pandas
import pandas as pd
from datetime import date
col  = pd.read_excel("workforce.xlsx", sheet_name="Colaboradores", parse_dates=["Data_Admissao"])
hist = pd.read_excel("workforce.xlsx", sheet_name="Historico",    parse_dates=["Data_Evento"])
year = date.today().year
saidas  = hist[(hist["Tipo_Evento"]=="Desligamento") & (hist["Data_Evento"].dt.year==year)].shape[0]
hc_fim  = (col["Status"]=="Ativo").sum()
hc_ini  = col[col["Data_Admissao"].dt.year < year].shape[0]
hc_med  = (hc_ini + hc_fim) / 2
turnover = round(saidas / hc_med * 100, 2) if hc_med > 0 else 0
print(f"Turnover Rate: {turnover}%")

Retention Rate
Benchmark: > 85% · Source: AIHR
Formula: Retention Rate (%) = 100 − Turnover Rate (%)
Or: (Active employees who stayed throughout period / HC at start) × 100
Excel
=100 - [célula_Turnover_Rate]
DAX
Retention Rate % = 100 - [Turnover Rate %]
SQL
SELECT 100 - ROUND(
    (SELECT COUNT(*) FROM fato_Historico WHERE Tipo_Evento='Desligamento'
     AND strftime('%Y',Data_Evento)=strftime('%Y','now')) * 100.0
    / NULLIF((SELECT COUNT(*) FROM dim_Colaboradores WHERE Status='Ativo'),0)
,2) AS retention_rate_pct;
Python
retention_rate = round(100 - turnover, 2)
print(f"Retention Rate: {retention_rate}%")

eNPS (Employee Net Promoter Score)
Benchmark: 20–40 · Source: LinkedIn Talent Trends
Formula: eNPS = ((Promoters − Detractors) / Total respondents) × 100
Scale: Promoters = 9–10 · Neutrals = 7–8 · Detractors = 0–6 · Range: −100 to +100
Excel
=(CONT.SES(Avaliacoes[Tipo_Avaliacao],"Clima_Organizacional",Avaliacoes[Nota_eNPS],">="&9)
 -CONT.SES(Avaliacoes[Tipo_Avaliacao],"Clima_Organizacional",Avaliacoes[Nota_eNPS],"<="&6))
/ CONT.SE(Avaliacoes[Tipo_Avaliacao],"Clima_Organizacional") * 100
DAX — correct pattern (FILTER, not CALCULATE on VAR)
eNPS =
VAR base  = FILTER(fato_Avaliacoes, fato_Avaliacoes[Tipo_Avaliacao] = "Clima_Organizacional")
VAR total = COUNTROWS(base)
VAR prom  = COUNTROWS(FILTER(base, fato_Avaliacoes[Nota_eNPS] >= 9))
VAR det   = COUNTROWS(FILTER(base, fato_Avaliacoes[Nota_eNPS] <= 6))
RETURN DIVIDE(prom - det, total, 0) * 100
DAX pitfall: CALCULATE(COUNTROWS(base)) where base is a VAR table does not filter correctly. Always use COUNTROWS(FILTER(base, condition)).
SQL
SELECT ROUND(
    (SUM(CASE WHEN Nota_eNPS >= 9 THEN 1.0 ELSE 0 END)
   - SUM(CASE WHEN Nota_eNPS <= 6 THEN 1.0 ELSE 0 END))
    / COUNT(*) * 100, 2) AS eNPS
FROM fato_Avaliacoes WHERE Tipo_Avaliacao = 'Clima_Organizacional';
Python
aval  = pd.read_excel("workforce.xlsx", sheet_name="Avaliacoes")
clima = aval[aval["Tipo_Avaliacao"] == "Clima_Organizacional"]
total = len(clima)
prom  = (clima["Nota_eNPS"] >= 9).sum()
det   = (clima["Nota_eNPS"] <= 6).sum()
enps  = round((prom - det) / total * 100, 2) if total > 0 else 0
print(f"eNPS: {enps}")

Absenteísmo
Benchmark: ≤ 3.5% · Source: AIHR
Formula: Absenteeism (%) = (Days absent / Available working days) × 100
Available working days = Working days in period × Number of employees
Excel
=SOMASES(Faltas[Dias_Ausentes], Faltas[Departamento],A2, Faltas[Mes],B2)
/ (DIATRABALHOTOTAL(Data_Inicio, Data_Fim) * Headcount) * 100
DAX
Dias Ausentes =
CALCULATE(SUM(fato_Historico[Dias_Ausentes]), fato_Historico[Tipo_Evento] = "Ausência")

Absenteísmo % = DIVIDE([Dias Ausentes],
    NETWORKDAYS(MIN(dim_dCalendario[Date]),MAX(dim_dCalendario[Date])) * [HC Ativo],
    0) * 100
SQL
SELECT Departamento,
    ROUND(SUM(Dias_Ausentes)*100.0
          /((SELECT COUNT(*) FROM dim_Colaboradores WHERE Status='Ativo')*22),2) AS absenteismo_pct
FROM fato_Historico WHERE Tipo_Evento='Ausência' GROUP BY Departamento;
Python
ausencias     = hist[hist["Tipo_Evento"]=="Ausência"]
total_ausente = ausencias["Dias_Ausentes"].sum()
dias_uteis    = 22 * len(col[col["Status"]=="Ativo"])
absenteismo   = round(total_ausente / dias_uteis * 100, 2) if dias_uteis > 0 else 0
print(f"Absenteísmo: {absenteismo}%")

Time to Fill
Benchmark: 30–45 days · Source: SHRM
Fórmula: TTF = Data da oferta aceita − Data de abertura da vaga (dias corridos)
Fonte: dim_Vagas filtrado por Motivo_Encerramento = 'Contratação'
Excel
=MÉDIASES(Vagas[Time_to_Fill], Vagas[Motivo_Encerramento],"Contratação", Vagas[Departamento],A2)
DAX
TTF Médio (dias) =
AVERAGEX(
    FILTER(dim_Vagas, dim_Vagas[Motivo_Encerramento] = "Contratação"),
    DATEDIFF(dim_Vagas[Data_Abertura], dim_Vagas[Data_Aceite], DAY)
)
SQL
SELECT Departamento,
    ROUND(AVG(JULIANDAY(Data_Aceite) - JULIANDAY(Data_Abertura)), 1) AS ttf_medio
FROM dim_Vagas WHERE Motivo_Encerramento = 'Contratação'
GROUP BY Departamento ORDER BY ttf_medio DESC;
Python
vagas  = pd.read_excel("workforce.xlsx", sheet_name="Vagas",
                       parse_dates=["Data_Abertura","Data_Aceite"])
filled = vagas[vagas["Motivo_Encerramento"]=="Contratação"].copy()
filled["ttf"] = (filled["Data_Aceite"] - filled["Data_Abertura"]).dt.days
print(f"TTF médio: {filled['ttf'].mean():.1f} dias")

Offer Acceptance Rate
Benchmark: > 85% · Source: Michael Page
Fórmula: OAR (%) = (Ofertas aceitas / Ofertas feitas) × 100
Proxy: se o ATS não rastreia ofertas, use Motivo_Encerramento = 'Contratação' como aceita e Oferta_Feita = 'S' como denominador.
Excel
=CONT.SES(Vagas[Oferta_Feita],"S",Vagas[Motivo_Encerramento],"Contratação")
/ CONT.SE(Vagas[Oferta_Feita],"S") * 100
DAX
Offer Acceptance Rate % =
DIVIDE(
    CALCULATE(COUNTROWS(dim_Vagas), dim_Vagas[Motivo_Encerramento]="Contratação", dim_Vagas[Oferta_Feita]="S"),
    CALCULATE(COUNTROWS(dim_Vagas), dim_Vagas[Oferta_Feita]="S"), 0
) * 100
SQL
SELECT ROUND(
    SUM(CASE WHEN Motivo_Encerramento='Contratação' THEN 1.0 ELSE 0 END)
    / NULLIF(SUM(CASE WHEN Oferta_Feita='S' THEN 1.0 ELSE 0 END),0) * 100, 2
) AS oar_pct FROM dim_Vagas;
Python
ofertas_feitas  = vagas[vagas["Oferta_Feita"]=="S"].shape[0]
ofertas_aceitas = vagas[(vagas["Oferta_Feita"]=="S") & (vagas["Motivo_Encerramento"]=="Contratação")].shape[0]
oar = round(ofertas_aceitas / ofertas_feitas * 100, 2) if ofertas_feitas > 0 else 0
print(f"Offer Acceptance Rate: {oar}%")

Cost per Hire
Benchmark: R$ 3,000–8,000 · Source: SHRM
Formula: CPH = (Internal + External costs) / Number of hires
Internal: recruiter hours, manager time · External: job boards, agencies, assessments
Excel
=SOMASES(Vagas[Custo_Total_Contratacao],Vagas[Motivo_Encerramento],"Contratação")
/CONT.SE(Vagas[Motivo_Encerramento],"Contratação")
DAX
Cost per Hire =
DIVIDE(
    CALCULATE(SUM(dim_Vagas[Custo_Total_Contratacao]), dim_Vagas[Motivo_Encerramento]="Contratação"),
    CALCULATE(COUNTROWS(dim_Vagas),                    dim_Vagas[Motivo_Encerramento]="Contratação"), 0
)
SQL
SELECT Departamento,
    ROUND(AVG(Custo_Total_Contratacao),2) AS cph_medio,
    COUNT(*)                              AS total_contratacoes
FROM dim_Vagas WHERE Motivo_Encerramento='Contratação'
GROUP BY Departamento ORDER BY cph_medio DESC;
Python
contratados = vagas[vagas["Motivo_Encerramento"]=="Contratação"]
cph = round(contratados["Custo_Total_Contratacao"].mean(), 2)
print(f"Cost per Hire médio: R$ {cph:,.2f}")

Quality of Hire
Benchmark: > 70/100 · Source: AIHR
Formula: Quality of Hire = (Performance Score + Retention Score) / 2 · Both on 0–100 scale.
Manager_Rating (0–5) → multiply × 20 to convert to 0–100. Retention Score: 100 if still active after 12 months; 0 otherwise.
DAX
Performance Score (0-100) =
AVERAGEX(FILTER(fato_Avaliacoes, fato_Avaliacoes[Tipo_Avaliacao]="Avaliacao_180"),
         fato_Avaliacoes[Media_Gestor] * 20)

Retention Score (0-100) =
DIVIDE(
    CALCULATE(COUNTROWS(dim_Colaboradores), dim_Colaboradores[Status]="Ativo",
              DATEDIFF(dim_Colaboradores[Data_Admissao], TODAY(), MONTH) >= 12),
    CALCULATE(COUNTROWS(dim_Colaboradores), DATEDIFF(dim_Colaboradores[Data_Admissao], TODAY(), MONTH) >= 12),
    0) * 100

Quality of Hire = DIVIDE([Performance Score (0-100)] + [Retention Score (0-100)], 2)
SQL
WITH perf AS (
    SELECT ID_Colaborador, AVG(Media_Gestor * 20) AS perf_score
    FROM fato_Avaliacoes WHERE Tipo_Avaliacao = 'Avaliacao_180' GROUP BY 1
),
ret AS (
    SELECT ID_Colaborador,
           CASE WHEN Status='Ativo' AND JULIANDAY('now')-JULIANDAY(Data_Admissao)>=365
                THEN 100 ELSE 0 END AS ret_score
    FROM dim_Colaboradores WHERE JULIANDAY('now')-JULIANDAY(Data_Admissao)>=365
)
SELECT ROUND(AVG((p.perf_score + r.ret_score)/2.0),2) AS quality_of_hire
FROM ret r JOIN perf p ON r.ID_Colaborador = p.ID_Colaborador;
Python
hoje = pd.Timestamp(date.today())
elegivel = col[((hoje-col["Data_Admissao"])/pd.Timedelta(days=365))>=1].copy()
elegivel["ret_score"] = (elegivel["Status"]=="Ativo").astype(int)*100
aval_180 = aval[aval["Tipo_Avaliacao"]=="Avaliacao_180"].groupby("ID_Colaborador")["Media_Gestor"].mean()*20
elegivel = elegivel.merge(aval_180.rename("perf_score"), on="ID_Colaborador", how="left")
elegivel["qoh"] = (elegivel["perf_score"].fillna(0) + elegivel["ret_score"]) / 2
print(f"Quality of Hire médio: {elegivel['qoh'].mean():.1f}")

Benchmark: < 10% · Source: SHRM
Fórmula: Voluntary Turnover (%) = (Saídas voluntárias / HC Médio) × 100
Fonte: fato_Historico com Tipo_Evento = 'Desligamento' E Motivo = 'Voluntário'

Voluntary Turnover % =
DIVIDE(

Time to Hire
Benchmark: 14–23 days · Source: LinkedIn Talent Trends
Formula: TTH = Date offer accepted − Date the hired candidate applied (days)
vs TTF: TTF measures from req opened; TTH measures the hired candidate's experience.
DAX
TTH Médio (dias) =
AVERAGEX(
    FILTER(dim_Vagas, dim_Vagas[Motivo_Encerramento]="Contratação"),
    DATEDIFF(dim_Vagas[Data_Candidatura_Contratado], dim_Vagas[Data_Aceite], DAY)
)
SQL
SELECT ROUND(AVG(JULIANDAY(Data_Aceite)-JULIANDAY(Data_Candidatura_Contratado)),1) AS tth_medio
FROM dim_Vagas WHERE Motivo_Encerramento='Contratação' AND Data_Candidatura_Contratado IS NOT NULL;
Python
filled["tth"] = (filled["Data_Aceite"] - filled["Data_Candidatura_Contratado"]).dt.days
print(f"Time to Hire médio: {filled['tth'].mean():.1f} dias")
TTF vs. TTH: Use TTF for capacity planning (how long until a seat is filled). Use TTH for candidate experience (how long they waited). Report both to TA leaders — they answer different questions.

How to turn data into answers leaders actually need

STAR Framework for People Analytics
Every analysis should answer: Situation → Trend → Action → Expected Result. Use this model to structure presentations for C-level and managers.
Why is our turnover above the industry average? +

3-layer diagnosis:

  1. Demographic layer — Segment turnover by department, age group, tenure (0–6m, 7–12m, 1–3y, 3+y) and manager. A 25% rate can hide one department at 60% and another at 5%.
  2. Time layer — Plot exits month by month. Seasonal peaks (Jan–Feb post-bonus, Jul–Aug) indicate financial-incentive retention, not genuine engagement.
  3. Reason layer — Cross fato_Historico[Reason] with exit date. If "external offer" dominates: compensation gap. If "climate/manager" dominates: leadership problem.
DAX — Turnover by Manager (Top 5 worst)
Turnover por Gestor =
VAR saidas =
    CALCULATE(
        COUNTROWS(fato_Historico),
        fato_Historico[Tipo_Evento] = "Desligamento"
    )
VAR hc_medio = [HC Médio]
RETURN DIVIDE(saidas, hc_medio, 0) * 100

Crie um visual de tabela com dim_Colaboradores[Gestor_Direto] no eixo e esta medida como valor. Ordene decrescente e aplique formatação condicional: ≥20% vermelho, 10–20% amarelo.

Recommended action: Present the turnover heat map to the CHRO before proposing any intervention. Avoid blanket solutions (e.g., across-the-board raises) when the problem is localized.

Which employees are most likely to leave in the next 90 days? +

Flight Risk Model — 5 signals:

SignalHow to measureSuggested weight
Individual eNPS ≤ 6fato_Avaliacoes[Nota_eNPS]30%
Performance ≤ 2/5 or ≥ 4.5/5fato_Avaliacoes[Media_Gestor]20%
18+ months in role without promotiondim_Colaboradores[Data_Ultima_Promocao]20%

Salary below band mediandim_Colaboradores[Salario] vs banda15%
Python — Flight Risk Score
import pandas as pd
from datetime import date

df = pd.read_excel("workforce.xlsx", parse_dates=["Data_Admissao","Data_Ultima_Promocao"])
hoje = pd.Timestamp(date.today())

df["meses_sem_promocao"] = ((hoje - df["Data_Ultima_Promocao"]) / pd.Timedelta(days=30)).round()
df["enps_baixo"]         = (df["Nota_eNPS"] <= 6).astype(int)
df["sem_promocao_flag"]  = (df["meses_sem_promocao"] >= 18).astype(int)
df["perf_extrema"]       = ((df["Media_Gestor"] <= 2) | (df["Media_Gestor"] >= 4.5)).astype(int)

df["flight_risk_score"] = (
    df["enps_baixo"]        * 30 +
    df["perf_extrema"]      * 20 +
    df["sem_promocao_flag"] * 20
) / 70  # normaliza 0-100

alto_risco = df[df["flight_risk_score"] >= 60].sort_values("flight_risk_score", ascending=False)
print(alto_risco[["Nome","Departamento","Gestor","flight_risk_score"]].head(20))

Privacy note: This model processes sensitive personal data. Ensure the purpose is documented, access is restricted to HRBPs and the direct manager, and no action reaches the employee without a concrete retention initiative attached.

Our hiring process is taking too long — where is the bottleneck? +

Break Time to Fill into funnel stages:

SQL — Average time per funnel stage
-- Requer colunas de data por etapa em dim_Vagas
SELECT
    Departamento,
    AVG(JULIANDAY(Data_Triagem)      - JULIANDAY(Data_Abertura))    AS dias_abertura_triagem,
    AVG(JULIANDAY(Data_Entrevista)   - JULIANDAY(Data_Triagem))     AS dias_triagem_entrevista,
    AVG(JULIANDAY(Data_Oferta)       - JULIANDAY(Data_Entrevista))  AS dias_entrevista_oferta,
    AVG(JULIANDAY(Data_Aceite)       - JULIANDAY(Data_Oferta))      AS dias_oferta_aceite,
    AVG(JULIANDAY(Data_Aceite)       - JULIANDAY(Data_Abertura))    AS time_to_fill_total
FROM dim_Vagas
WHERE Motivo_Encerramento = 'Contratação'
GROUP BY Departamento
ORDER BY time_to_fill_total DESC;

Interpretação rápida:

  • Screening→Interview > 7 days: Overloaded recruiter or ambiguous criteria → revise screening scorecard.
  • Interview→Offer > 5 days: Slow internal approval → simplified authority for operational roles.
  • Offer→Accept > 3 days: Below-expectation offer or active competition → salary benchmark before the offer.

Benchmark target: TTF ≤ 30 days (individual contributors), ≤ 45 days (managers/senior specialists). Source: SHRM.

How do I demonstrate the ROI of a training initiative? +

Modelo de ROI de L&D (Kirkpatrick + Phillips):

  1. Level 1 — Reaction: Post-training survey (program NPS). Target: ≥ 70.
  2. Level 2 — Learning: Pre-test vs. post-test. Target: ≥ 20 pp gain.
  3. Level 3 — Behavior: Manager assessment 90 days later. Use fato_Avaliacoes com Tipo_Avaliacao = 'Pos_Treinamento'.
  4. Level 4 — Result: Turnover reduction, productivity gains, error rate drop — measurable in already-tracked KPIs.
Formula — Training ROI
ROI (%) = ((Benefício Líquido - Custo Total do Programa) / Custo Total do Programa) × 100

Exemplo:
  Custo do programa de liderança: R$ 80.000
  Redução de turnover de gestores (3 saídas evitadas × R$ 40.000 custo médio de substituição):
      Benefício = 3 × R$ 40.000 = R$ 120.000
  ROI = ((120.000 - 80.000) / 80.000) × 100 = 50%

Tip: Replacement cost ranges from 50% (operational) to 200% (technical/management) of annual salary. Use the conservative 50% for ROI calculations — the argument is stronger when the pessimistic scenario still justifies the investment.

How do I present People Analytics to the CEO without losing the thread? +

The 3-Slide Rule for People Analytics at C-level:

  1. Slide 1 — Current situation: 3 KPIs max with benchmark context. E.g.: "Turnover 18% (benchmark: 12%). Estimated cost: R$ 2.4M/year."
  2. Slide 2 — Root cause: One chart with the most relevant breakdown. E.g.: "72% of exits happen in the first 12 months and concentrate around 3 managers."
  3. Slide 3 — Action proposal with ROI: "Structured onboarding program + coaching for the 3 managers. Cost: R$ 120K. Expected 30% reduction in early turnover = R$ 720K saved."

Avoid: Dashboards with 15 KPIs, percentages without benchmark context, and recommendations without estimated cost/benefit. CEOs make decisions based on financial impact — always translate your data.

CEO meeting opening template:
"We have a R$ [X] per year problem. The main cause is [Y]. Proposed solution with an investment of R$ [Z] and expected return of [ROI%] in [timeframe]."
How do I calculate the real cost of a bad hire? +

Components of a bad hire cost:

ComponentTypical estimate
Recruitment Cost (CPH)R$ 3,000–15,000
Onboarding and initial training1–3 months salary
Lost productivity (ramp-up)3–6 months salary
Team impact (morale, rework)20–30% of team productivity for 1–3 months
New hire (if fired)50–200% of annual salary
Conservative total1.5× to 3× the annual salary of the role
Quick estimate
Bad Hire Cost =
    CPH
    + (Monthly_Salary × Training_Months)
    + (Monthly_Salary × Lost_Productivity_Months × 0.5)
    + CPH  -- new recruitment process

Example (Senior Analyst, salary R$ 8,000/mo):
    CPH = R$ 6,000
    Training = 8,000 × 2 = R$ 16,000
    Productivity = 8,000 × 4 × 0.5 = R$ 16,000
    New search = R$ 6,000
    TOTAL = R$ 44,000 (≈ 5.5 monthly salaries)

Use this number to justify investment in Quality of Hire: a more robust selection process that costs R$ 10K more but prevents a R$ 44K bad hire has an ROI of 340%.

Our eNPS dropped 15 points — how do we investigate and act? +

eNPS drop investigation protocol:

  1. Segment before acting: Is the drop widespread or concentrated in a specific area/level/manager? A 15-point company-wide drop may be 40 points in one area and 0 in others.
  2. Cross with quantitative data: Was there an increase in turnover, absenteeism, or a performance drop in the same period? Correlations confirm or rule out hypotheses.
  3. Focus groups with detractors (anonymized): eNPS measures intensity, not reason. Use qualitative interviews with a representative sample of detractors (6–8 people) to understand the "why".
  4. 30-day action plan: Communicate to the company that the data was analyzed and that there is a plan. Silence after a survey is one of the greatest trust-destroyers in HR.
DAX — eNPS por Departamento (variação vs. período anterior)
eNPS Atual =
VAR base  = FILTER(fato_Avaliacoes, fato_Avaliacoes[Tipo_Avaliacao] = "Clima_Organizacional")
VAR total = COUNTROWS(base)
VAR prom  = COUNTROWS(FILTER(base, fato_Avaliacoes[Nota_eNPS] >= 9))
VAR det   = COUNTROWS(FILTER(base, fato_Avaliacoes[Nota_eNPS] <= 6))
RETURN DIVIDE(prom - det, total, 0) * 100

eNPS Período Anterior =
CALCULATE([eNPS Atual], DATEADD(dim_dCalendario[Date], -6, MONTH))

Variação eNPS = [eNPS Atual] - [eNPS Período Anterior]

Action benchmark: eNPS ≥ 30 = healthy; 0–29 = improvement zone; below 0 = critical — immediate action required.

people_analytics_pipeline.py — Complete skeleton
import pandas as pd
from datetime import date

# ── 1. EXTRACTION ────────────────────────────────────────────
def extract_data(excel_path: str) -> dict[str, pd.DataFrame]:
    """Reads all sheets from the HR file."""
    return pd.read_excel(
        caminho_excel,
        sheet_name=["Employees", "History", "Assessments", "Vacancies"],
        parse_dates=True
    )

# ── 2. TRANSFORMATION ───────────────────────────────────────
def calculate_kpis(data: dict) -> pd.DataFrame:
    hoje = pd.Timestamp(date.today())
    col  = data["Employees"]
    hist = data["History"]
    aval = data["Assessments"]

    # Current headcount
    hc_atual = col[col["Status"] == "Ativo"].shape[0]

    # Turnover Rate (period: current year)
    ano_atual = hoje.year
    saidas = hist[
        (hist["Tipo_Evento"] == "Desligamento") &
        (hist["Data_Evento"].dt.year == ano_atual)
    ].shape[0]

    hc_inicio = col[col["Data_Admissao"].dt.year < ano_atual].shape[0]
    hc_medio  = (hc_inicio + hc_atual) / 2
    turnover  = round((saidas / hc_medio * 100), 2) if hc_medio > 0 else 0

    # eNPS
    clima = aval[aval["Tipo_Avaliacao"] == "Clima_Organizacional"]
    total = len(clima)
    prom  = (clima["Nota_eNPS"] >= 9).sum()
    det   = (clima["Nota_eNPS"] <= 6).sum()
    enps  = round(((prom - det) / total * 100), 2) if total > 0 else 0

    return pd.DataFrame([{
        "Data":          hoje.date(),
        "HC_Atual":      hc_atual,
        "Turnover_Pct":  turnover,
        "eNPS":          enps
    }])

# ── 3. LOAD ──────────────────────────────────────────────────
def save_result(df: pd.DataFrame, destination: str) -> None:
    df.to_excel(destination, index=False)
    print(f"KPIs saved to: {destination}")

# ── EXECUTION ────────────────────────────────────────────────
if __name__ == "__main__":
    data    = extract_data("workforce.xlsx")
    kpis    = calculate_kpis(data)
    save_result(kpis, "kpis_people_analytics.xlsx")

SQL — Reference queries for People Analytics

Consolidated view of monthly KPIs
CREATE VIEW vw_kpis_people_analytics AS
WITH
  -- Average headcount by month
  hc_mensal AS (
    SELECT
      strftime('%Y-%m', Data_Evento) AS ano_mes,
      COUNT(DISTINCT ID_Colaborador)  AS hc
    FROM fato_Historico
    WHERE Tipo_Evento IN ('Admission','Active')
    GROUP BY 1
  ),
  -- Exits by month
  saidas_mensais AS (
    SELECT
      strftime('%Y-%m', Data_Evento) AS ano_mes,
      COUNT(*)                        AS saidas,
      SUM(CASE WHEN Motivo = 'Voluntary' THEN 1 ELSE 0 END) AS voluntary_exits
    FROM fato_Historico
    WHERE Tipo_Evento = 'Termination'
    GROUP BY 1
  ),
  -- eNPS by month
  enps_mensal AS (
    SELECT
      strftime('%Y-%m', Data_Avaliacao) AS ano_mes,
      ROUND(
        (SUM(CASE WHEN Nota_eNPS >= 9 THEN 1.0 ELSE 0 END) -
         SUM(CASE WHEN Nota_eNPS <= 6 THEN 1.0 ELSE 0 END))
        / COUNT(*) * 100, 2
      ) AS enps
    FROM fato_Avaliacoes
    WHERE Assessment_Type = 'Organizational_Climate'
    GROUP BY 1
  )
SELECT
  h.ano_mes,
  h.hc                                              AS headcount,
  s.saidas,
  ROUND(s.exits * 100.0 / h.hc, 2)                  AS turnover_pct,
  ROUND(s.voluntary_exits * 100.0 / h.hc, 2)        AS vol_turnover_pct,
  e.enps
FROM hc_mensal h
LEFT JOIN saidas_mensais s ON h.ano_mes = s.ano_mes
LEFT JOIN enps_mensal    e ON h.ano_mes = e.ano_mes
ORDER BY h.ano_mes;
