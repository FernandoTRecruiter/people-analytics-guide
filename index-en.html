Turnover Rate
Benchmark: 10–15% · Source: SHRM
Formula: Turnover Rate (%) = (Exits in period / Average HC) × 100
Average HC = (HC at start of period + HC at end) / 2 · Source table: fato_Historico (event type = "Termination")
Excel — Turnover Rate
=COUNTIFS(
    History[Event_Type],  "Termination",
    History[Event_Date], ">="&DATE(YEAR(TODAY()),1,1),
    History[Event_Date], "<="&TODAY()
) / ((HC_Start + HC_End) / 2) * 100

Name cell B2 = HC_Start (headcount Jan 1) and B3 = HC_End (current headcount). Use COUNTIFS to count only Termination events within the desired period.

DAX — Power BI
Exits in Period =
CALCULATE(
    COUNTROWS(fato_Historico),
    fato_Historico[Event_Type] = "Termination"
)

Average HC =
DIVIDE(
    CALCULATE(COUNTROWS(dim_Colaboradores), dim_Colaboradores[Status] = "Active",
              DATEADD(dim_dCalendario[Date], -12, MONTH))
    + CALCULATE(COUNTROWS(dim_Colaboradores), dim_Colaboradores[Status] = "Active"),
    2
)

Turnover Rate % = DIVIDE([Exits in Period], [Average HC], 0) * 100
SQL
WITH exits AS (
    SELECT COUNT(*) AS total_exits
    FROM fato_Historico
    WHERE Event_Type = 'Termination'
      AND strftime('%Y', Event_Date) = strftime('%Y', 'now')
),
headcount AS (
    SELECT COUNT(*) AS hc
    FROM dim_Colaboradores
    WHERE Status = 'Active'
)
SELECT
    e.total_exits,
    h.hc AS current_hc,
    ROUND(e.total_exits * 100.0 / h.hc, 2) AS turnover_rate_pct
FROM exits e, headcount h;
Python — pandas
import pandas as pd
from datetime import date

col  = pd.read_excel("workforce.xlsx", sheet_name="Employees",  parse_dates=["Hire_Date"])
hist = pd.read_excel("workforce.xlsx", sheet_name="History",    parse_dates=["Event_Date"])

year = date.today().year
exits = hist[
    (hist["Event_Type"] == "Termination") &
    (hist["Event_Date"].dt.year == year)
].shape[0]

hc_end   = (col["Status"] == "Active").sum()
hc_start = col[col["Hire_Date"].dt.year < year].shape[0]
avg_hc   = (hc_start + hc_end) / 2

turnover = round(exits / avg_hc * 100, 2) if avg_hc > 0 else 0
print(f"Turnover Rate: {turnover}%")

Retention Rate
Benchmark: > 85% · Source: AIHR
Formula: Retention Rate (%) = 100 − Turnover Rate (%)
Or directly: (Active employees who stayed throughout the period / HC at start) × 100
Excel
=100 - [Turnover_Rate_cell]
-- Or direct:
=COUNTIFS(
    Employees[Status],    "Active",
    Employees[Hire_Date], "<"&DATE(YEAR(TODAY()),1,1)
) / HC_Start * 100
DAX
Retention Rate % = 100 - [Turnover Rate %]
SQL
SELECT 100 - turnover_rate_pct AS retention_rate_pct
FROM (
    SELECT ROUND(
        (SELECT COUNT(*) FROM fato_Historico
         WHERE Event_Type = 'Termination'
           AND strftime('%Y', Event_Date) = strftime('%Y','now')) * 100.0
        / NULLIF((SELECT COUNT(*) FROM dim_Colaboradores WHERE Status='Active'), 0)
    , 2) AS turnover_rate_pct
);
Python
retention_rate = round(100 - turnover, 2)
print(f"Retention Rate: {retention_rate}%")

eNPS (Employee Net Promoter Score)
Benchmark: 20–40 · Source: LinkedIn Talent Trends
Formula: eNPS = ((Promoters − Detractors) / Total respondents) × 100
Scale: Promoters = 9–10 · Neutrals = 7–8 · Detractors = 0–6
Range: −100 to +100 (not a percentage — no % symbol)
Excel
=(COUNTIFS(Survey[Type],"Climate",Survey[eNPS_Score],">="&9)
 -COUNTIFS(Survey[Type],"Climate",Survey[eNPS_Score],"<="&6))
/ COUNTIF(Survey[Type],"Climate")
* 100
DAX — correct pattern (FILTER, not CALCULATE on VAR)
eNPS =
VAR base  = FILTER(fato_Avaliacoes, fato_Avaliacoes[Survey_Type] = "Climate")
VAR total = COUNTROWS(base)
VAR prom  = COUNTROWS(FILTER(base, fato_Avaliacoes[eNPS_Score] >= 9))
VAR det   = COUNTROWS(FILTER(base, fato_Avaliacoes[eNPS_Score] <= 6))
RETURN DIVIDE(prom - det, total, 0) * 100
DAX pitfall: CALCULATE(COUNTROWS(base)) where base is a VAR table does not filter correctly. Always use COUNTROWS(FILTER(base, condition)).
SQL
SELECT
    ROUND(
        (SUM(CASE WHEN eNPS_Score >= 9 THEN 1.0 ELSE 0 END)
       - SUM(CASE WHEN eNPS_Score <= 6 THEN 1.0 ELSE 0 END))
        / COUNT(*) * 100, 2
    ) AS eNPS
FROM fato_Avaliacoes
WHERE Survey_Type = 'Climate';
Python
climate = aval[aval["Survey_Type"] == "Climate"]
total   = len(climate)
prom    = (climate["eNPS_Score"] >= 9).sum()
det     = (climate["eNPS_Score"] <= 6).sum()
enps    = round((prom - det) / total * 100, 2) if total > 0 else 0
print(f"eNPS: {enps}")

Absenteeism Rate
Benchmark: ≤ 3.5% · Source: AIHR
Formula: Absenteeism (%) = (Days absent / Available working days) × 100
Available working days = Working days in period × Number of employees
Excel
=SUMIFS(Absences[Days_Absent],
        Absences[Department], A2,
        Absences[Month], B2)
/ (NETWORKDAYS(Start_Date, End_Date) * Headcount) * 100
DAX
Days Absent =
CALCULATE(
    SUM(fato_Historico[Days_Absent]),
    fato_Historico[Event_Type] = "Absence"
)

Working Days =
NETWORKDAYS(
    MIN(dim_dCalendario[Date]),
    MAX(dim_dCalendario[Date])
) * [Active HC]

Absenteeism % = DIVIDE([Days Absent], [Working Days], 0) * 100
SQL
SELECT
    Department,
    SUM(Days_Absent) AS total_absent_days,
    (SELECT COUNT(*) FROM dim_Colaboradores WHERE Status = 'Active') * 22 AS working_days,
    ROUND(SUM(Days_Absent) * 100.0
          / ((SELECT COUNT(*) FROM dim_Colaboradores WHERE Status='Active') * 22)
    , 2) AS absenteeism_pct
FROM fato_Historico
WHERE Event_Type = 'Absence'
GROUP BY Department;
Python
absences = hist[hist["Event_Type"] == "Absence"]
total_absent  = absences["Days_Absent"].sum()
working_days  = 22 * len(col[col["Status"] == "Active"])
absenteeism   = round(total_absent / working_days * 100, 2) if working_days > 0 else 0
print(f"Absenteeism: {absenteeism}%")

Time to Fill
Benchmark: 30–45 days · Source: SHRM
Formula: Time to Fill = Date offer accepted − Date requisition opened (calendar days)
Source: dim_Vagas · Filter: Closure_Reason = 'Hire'
Excel
=AVERAGEIFS(
    Reqs[Time_to_Fill],
    Reqs[Closure_Reason], "Hire",
    Reqs[Department],     A2
)
DAX
Avg Time to Fill (days) =
AVERAGEX(
    FILTER(dim_Vagas, dim_Vagas[Closure_Reason] = "Hire"),
    DATEDIFF(dim_Vagas[Open_Date], dim_Vagas[Accepted_Date], DAY)
)
SQL
SELECT
    Department,
    ROUND(AVG(JULIANDAY(Accepted_Date) - JULIANDAY(Open_Date)), 1) AS avg_time_to_fill
FROM dim_Vagas
WHERE Closure_Reason = 'Hire'
  AND Accepted_Date IS NOT NULL
GROUP BY Department
ORDER BY avg_time_to_fill DESC;
Python
vagas = pd.read_excel("workforce.xlsx", sheet_name="Reqs",
                      parse_dates=["Open_Date","Accepted_Date"])
filled = vagas[vagas["Closure_Reason"] == "Hire"].copy()
filled["ttf"] = (filled["Accepted_Date"] - filled["Open_Date"]).dt.days
print(f"Avg Time to Fill: {filled['ttf'].mean():.1f} days")
print(filled.groupby("Department")["ttf"].mean().sort_values(ascending=False))

Offer Acceptance Rate
Benchmark: > 85% · Source: Michael Page
Formula: OAR (%) = (Offers accepted / Offers made) × 100
Proxy: if your ATS does not track offers, use Closure_Reason = 'Hire' as "accepted" and Offer_Made = 'Y' as denominator.
Excel
=COUNTIFS(Reqs[Offer_Made],"Y", Reqs[Closure_Reason],"Hire")
/ COUNTIF(Reqs[Offer_Made],"Y") * 100
DAX
Offer Acceptance Rate % =
DIVIDE(
    CALCULATE(COUNTROWS(dim_Vagas), dim_Vagas[Closure_Reason] = "Hire",
                                    dim_Vagas[Offer_Made]     = "Y"),
    CALCULATE(COUNTROWS(dim_Vagas), dim_Vagas[Offer_Made]     = "Y"),
    0
) * 100
SQL
SELECT
    ROUND(
        SUM(CASE WHEN Closure_Reason = 'Hire' THEN 1.0 ELSE 0 END)
        / NULLIF(SUM(CASE WHEN Offer_Made = 'Y' THEN 1.0 ELSE 0 END), 0)
        * 100, 2
    ) AS offer_acceptance_rate_pct
FROM dim_Vagas;
Python
offers_made    = vagas[vagas["Offer_Made"] == "Y"].shape[0]
offers_accepted = vagas[(vagas["Offer_Made"] == "Y") &
                        (vagas["Closure_Reason"] == "Hire")].shape[0]
oar = round(offers_accepted / offers_made * 100, 2) if offers_made > 0 else 0
print(f"Offer Acceptance Rate: {oar}%")

Cost per Hire
Benchmark: R$ 3,000–8,000 · Source: SHRM
Formula: CPH = (Internal costs + External costs) / Number of hires
Internal: recruiter hours, hiring manager time · External: job boards, agencies, background checks, assessments
Excel
=SUMIFS(Reqs[Total_Hire_Cost], Reqs[Closure_Reason],"Hire")
/ COUNTIF(Reqs[Closure_Reason],"Hire")
DAX
Cost per Hire =
DIVIDE(
    CALCULATE(SUM(dim_Vagas[Total_Hire_Cost]),   dim_Vagas[Closure_Reason] = "Hire"),
    CALCULATE(COUNTROWS(dim_Vagas),              dim_Vagas[Closure_Reason] = "Hire"),
    0
)
SQL
SELECT
    Department,
    ROUND(AVG(Total_Hire_Cost), 2) AS avg_cost_per_hire,
    COUNT(*)                        AS total_hires
FROM dim_Vagas
WHERE Closure_Reason = 'Hire'
GROUP BY Department
ORDER BY avg_cost_per_hire DESC;
Python
hired = vagas[vagas["Closure_Reason"] == "Hire"]
cph = round(hired["Total_Hire_Cost"].mean(), 2)
print(f"Cost per Hire: R$ {cph:,.2f}")

Quality of Hire
Benchmark: > 70/100 · Source: AIHR
Formula: Quality of Hire = (Performance Score + Retention Score) / 2
Both components on a 0–100 scale. Manager_Rating (0–5) → multiply × 20 to convert to 0–100.
Retention Score: 100 if employee is still active 12+ months after hire; 0 otherwise.
DAX
Performance Score (0-100) =
AVERAGEX(
    FILTER(fato_Avaliacoes, fato_Avaliacoes[Survey_Type] = "180_Assessment"),
    fato_Avaliacoes[Manager_Rating] * 20
)

Retention Score (0-100) =
DIVIDE(
    CALCULATE(COUNTROWS(dim_Colaboradores),
              dim_Colaboradores[Status] = "Active",
              DATEDIFF(dim_Colaboradores[Hire_Date], TODAY(), MONTH) >= 12),
    CALCULATE(COUNTROWS(dim_Colaboradores),
              DATEDIFF(dim_Colaboradores[Hire_Date], TODAY(), MONTH) >= 12),
    0
) * 100

Quality of Hire = DIVIDE([Performance Score (0-100)] + [Retention Score (0-100)], 2)
SQL
WITH perf AS (
    SELECT ID_Employee, AVG(Manager_Rating * 20) AS perf_score
    FROM fato_Avaliacoes WHERE Survey_Type = '180_Assessment'
    GROUP BY ID_Employee
),
retention AS (
    SELECT ID_Employee,
           CASE WHEN Status = 'Active'
                 AND JULIANDAY('now') - JULIANDAY(Hire_Date) >= 365
                THEN 100 ELSE 0 END AS ret_score
    FROM dim_Colaboradores
    WHERE JULIANDAY('now') - JULIANDAY(Hire_Date) >= 365
)
SELECT ROUND(AVG((p.perf_score + r.ret_score) / 2.0), 2) AS quality_of_hire
FROM retention r
JOIN perf p ON r.ID_Employee = p.ID_Employee;
Python
hoje = pd.Timestamp(date.today())
# Employees hired 12+ months ago
eligible = col[((hoje - col["Hire_Date"]) / pd.Timedelta(days=365)) >= 1].copy()
eligible["ret_score"] = (eligible["Status"] == "Active").astype(int) * 100

perf_180 = aval[aval["Survey_Type"] == "180_Assessment"].groupby("ID_Employee")["Manager_Rating"].mean() * 20
eligible = eligible.merge(perf_180.rename("perf_score"), on="ID_Employee", how="left")
eligible["quality_of_hire"] = (eligible["perf_score"].fillna(0) + eligible["ret_score"]) / 2
print(f"Avg Quality of Hire: {eligible['quality_of_hire'].mean():.1f}")

Voluntary Turnover
Benchmark: < 10% · Source: SHRM
Formula: Voluntary Turnover (%) = (Voluntary exits / Average HC) × 100
Source: fato_Historico filtered by Event_Type = 'Termination' AND Reason = 'Voluntary'
DAX
Voluntary Turnover % =
DIVIDE(
    CALCULATE(COUNTROWS(fato_Historico),
              fato_Historico[Event_Type] = "Termination",
              fato_Historico[Reason]     = "Voluntary"),
    [Average HC], 0
) * 100
SQL
SELECT
    ROUND(
        SUM(CASE WHEN Event_Type='Termination' AND Reason='Voluntary' THEN 1.0 ELSE 0 END)
        / NULLIF((SELECT COUNT(*) FROM dim_Colaboradores WHERE Status='Active'), 0)
        * 100, 2
    ) AS voluntary_turnover_pct
FROM fato_Historico
WHERE strftime('%Y', Event_Date) = strftime('%Y','now');
Python
vol_exits = hist[
    (hist["Event_Type"] == "Termination") &
    (hist["Reason"]     == "Voluntary") &
    (hist["Event_Date"].dt.year == year)
].shape[0]
vol_turnover = round(vol_exits / avg_hc * 100, 2) if avg_hc > 0 else 0
print(f"Voluntary Turnover: {vol_turnover}%")

Time to Hire
Benchmark: 14–23 days · Source: LinkedIn Talent Trends
Formula: Time to Hire = Date offer accepted − Date candidate applied (days)
Difference from TTF: TTF measures from req opened; TTH measures from the hired candidate's application. Both are useful — TTF for planning, TTH for candidate experience.
DAX
Avg Time to Hire (days) =
AVERAGEX(
    FILTER(dim_Vagas, dim_Vagas[Closure_Reason] = "Hire"),
    DATEDIFF(dim_Vagas[Hired_Application_Date], dim_Vagas[Accepted_Date], DAY)
)
SQL
SELECT
    ROUND(AVG(JULIANDAY(Accepted_Date) - JULIANDAY(Hired_Application_Date)), 1)
        AS avg_time_to_hire
FROM dim_Vagas
WHERE Closure_Reason = 'Hire'
  AND Hired_Application_Date IS NOT NULL;
Python
filled["tth"] = (filled["Accepted_Date"] - filled["Hired_Application_Date"]).dt.days
print(f"Avg Time to Hire: {filled['tth'].mean():.1f} days")
TTF vs. TTH — which to use when:
Use Time to Fill for capacity planning (how long until a seat is filled). Use Time to Hire for candidate experience (how long a specific person waited from application to offer). Report both to TA leaders — they answer different questions.

Business Questions

How to turn data into answers leaders actually need

STAR Framework for People Analytics
Every analysis should answer: Situation → Trend → Action → Expected Result. Use this model to structure presentations for C-level and managers.
Why is our turnover above the industry average?+

3-layer diagnosis:

  1. Demographic layer — Segment turnover by department, age group, tenure band (0–6m, 7–12m, 1–3y, 3+y) and manager. A 25% turnover can hide one department at 60% and another at 5%.
  2. Time layer — Plot exits month by month. Seasonal peaks (Jan–Feb post-bonus, Jul–Aug) indicate retention by financial incentive, not genuine engagement.
  3. Reason layer — Cross fato_Historico[Reason] with exit date. If "external offer" dominates, it's a compensation competitiveness problem; if "climate/manager" dominates, it's a leadership problem.
DAX — Turnover by Manager (Top 5 worst)
Turnover by Manager =
VAR exits   = CALCULATE(COUNTROWS(fato_Historico), fato_Historico[Event_Type] = "Termination")
VAR avg_hc  = [Average HC]
RETURN DIVIDE(exits, avg_hc, 0) * 100

Create a table visual with dim_Colaboradores[Manager] on the axis and this measure as the value. Sort descending, apply conditional formatting: ≥20% red, 10–20% yellow.

Recommended action: Present the "turnover heat map" to the CHRO before proposing any intervention. Avoid one-size-fits-all solutions (e.g., across-the-board raises) when the problem is localized.

Which employees are most likely to leave in the next 90 days?+

Flight Risk Model — 5 signals:

SignalHow to measureSuggested weight
Individual eNPS ≤ 6fato_Avaliacoes[eNPS_Score]30%
Performance ≤ 2/5 or ≥ 4.5/5fato_Avaliacoes[Manager_Rating]20%
18+ months in role without promotiondim_Colaboradores[Last_Promotion_Date]20%
Manager with historical turnover > 20%Derived measure15%
Salary below band mediandim_Colaboradores[Salary] vs band15%
Python — Flight Risk Score
df["months_no_promo"] = ((hoje - df["Last_Promotion_Date"]) / pd.Timedelta(days=30)).round()
df["enps_low"]        = (df["eNPS_Score"] <= 6).astype(int)
df["no_promo_flag"]   = (df["months_no_promo"] >= 18).astype(int)
df["extreme_perf"]    = ((df["Manager_Rating"] <= 2) | (df["Manager_Rating"] >= 4.5)).astype(int)

df["flight_risk_score"] = (
    df["enps_low"]      * 30 +
    df["extreme_perf"]  * 20 +
    df["no_promo_flag"] * 20
) / 70  # normalize 0-100

high_risk = df[df["flight_risk_score"] >= 60].sort_values("flight_risk_score", ascending=False)
print(high_risk[["Name","Department","Manager","flight_risk_score"]].head(20))

Privacy note: This model processes sensitive personal data. Ensure the purpose is documented, access is restricted to HRBPs and the direct manager, and no communication reaches the employee without a concrete retention action attached.

Our hiring process is taking too long — where is the bottleneck?+

Break Time to Fill into stages:

SQL — Average time per funnel stage
SELECT
    Department,
    AVG(JULIANDAY(Screening_Date)   - JULIANDAY(Open_Date))      AS days_open_to_screen,
    AVG(JULIANDAY(Interview_Date)   - JULIANDAY(Screening_Date)) AS days_screen_to_interview,
    AVG(JULIANDAY(Offer_Date)       - JULIANDAY(Interview_Date)) AS days_interview_to_offer,
    AVG(JULIANDAY(Accepted_Date)    - JULIANDAY(Offer_Date))     AS days_offer_to_accept,
    AVG(JULIANDAY(Accepted_Date)    - JULIANDAY(Open_Date))      AS ttf_total
FROM dim_Vagas
WHERE Closure_Reason = 'Hire'
GROUP BY Department
ORDER BY ttf_total DESC;
  • Screening→Interview > 7 days: Overloaded recruiter or ambiguous screening criteria → revise scorecard.
  • Interview→Offer > 5 days: Slow internal approval (committee, VP) → create simplified approval authority for operational roles.
  • Offer→Accept > 3 days: Below-expectation offer or active competition → benchmark salary before making the offer.
How do I demonstrate the ROI of a training initiative?+

L&D ROI Model (Kirkpatrick + Phillips):

  1. Level 1 — Reaction: Post-training survey (program NPS). Target: ≥ 70.
  2. Level 2 — Learning: Pre-test vs. post-test. Target: ≥ 20 pp gain.
  3. Level 3 — Behavior: Manager assessment 90 days later. Use fato_Avaliacoes with Survey_Type = 'Post_Training'.
  4. Level 4 — Result: Turnover reduction, productivity increase, error rate drop — measurable in already-tracked KPIs.
Formula — Training ROI
ROI (%) = ((Net Benefit - Total Program Cost) / Total Program Cost) × 100

Example:
  Leadership program cost: $80,000
  Turnover reduction (3 avoided exits × $40,000 avg replacement cost):
      Benefit = 3 × $40,000 = $120,000
  ROI = ((120,000 - 80,000) / 80,000) × 100 = 50%

Tip: Use 50% of annual salary as the conservative replacement cost estimate (vs. 200% for senior roles). The argument is stronger when the "pessimistic" scenario still justifies the investment.

Absenteeism in our production floor is at 8% — what do we do?+

First, classify the absenteeism:

TypeTypical causeIntervention
Medical (doctor's note)Illness, accidents, ergonomicsHealth program, ergonomics assessment
UnexcusedDisengagement, manager conflictStructured conversation (SBI-E), development plan
Legal leaveMaternity, paternity, jury dutyCoverage planning — not a problem
Recurring Mon/Fri patternHidden presenteeismEngagement survey, workload analysis

Benchmark: Healthy absenteeism ≤ 3.5% (AIHR). 3.5–6% is a watch zone; above 6% requires a formal action plan with HR and occupational health.

Caution: High absenteeism in production often indicates work accidents or inadequate ergonomics — involve occupational health before treating it as a disciplinary matter.

How do I present People Analytics to the CEO without losing the thread?+

The 3-slide rule for People Analytics at C-level:

  1. Slide 1 — Current situation: 3 KPIs maximum with benchmark context. E.g.: "Turnover 18% (benchmark: 12%). Estimated cost: $800K/year."
  2. Slide 2 — Root cause: One chart with the most relevant segmentation. E.g.: "72% of exits occur in the first 12 months and concentrate in 3 managers."
  3. Slide 3 — Action proposal with ROI: "Structured onboarding program + coaching for the 3 managers. Cost: $40K. Expected 30% reduction in early turnover = $240K saved."

Our eNPS dropped 15 points — how do we investigate and act?+

eNPS drop investigation protocol:

  1. Segment before acting: Is the drop widespread or concentrated in a specific area/level/manager?
  2. Cross with quantitative data: Did turnover or absenteeism rise in the same period? Correlations confirm or rule out hypotheses.
  3. Focus groups with (anonymized) detractors: eNPS measures intensity, not reason. Use qualitative interviews with a representative sample.
  4. 30-day action plan: Communicate to the organization that data was analyzed and a plan exists. Silence after a survey is one of the biggest HR trust destroyers.
DAX — eNPS variation vs. previous period
eNPS Current =
VAR base  = FILTER(fato_Avaliacoes, fato_Avaliacoes[Survey_Type] = "Climate")
VAR total = COUNTROWS(base)
VAR prom  = COUNTROWS(FILTER(base, fato_Avaliacoes[eNPS_Score] >= 9))
VAR det   = COUNTROWS(FILTER(base, fato_Avaliacoes[eNPS_Score] <= 6))
RETURN DIVIDE(prom - det, total, 0) * 100

eNPS Previous Period =
CALCULATE([eNPS Current], DATEADD(dim_dCalendario[Date], -6, MONTH))

eNPS Change = [eNPS Current] - [eNPS Previous Period]

Action benchmarks: eNPS ≥ 30 = healthy; 0–29 = improvement zone; below 0 = critical — immediate action required.

import pandas as pd
from datetime import date

# ── 1. EXTRACT ────────────────────────────────────────────────
def extract_data(excel_path: str) -> dict[str, pd.DataFrame]:
    """Reads all sheets from the HR workbook."""
    return pd.read_excel(
        excel_path,
        sheet_name=["Employees", "History", "Assessments", "Reqs"],
        parse_dates=True
    )

# ── 2. TRANSFORM ──────────────────────────────────────────────
def calculate_kpis(data: dict) -> pd.DataFrame:
    today = pd.Timestamp(date.today())
    col   = data["Employees"]
    hist  = data["History"]
    aval  = data["Assessments"]

    hc_current = col[col["Status"] == "Active"].shape[0]
    year = today.year
    exits = hist[
        (hist["Event_Type"] == "Termination") &
        (hist["Event_Date"].dt.year == year)
    ].shape[0]
    hc_start = col[col["Hire_Date"].dt.year < year].shape[0]
    avg_hc   = (hc_start + hc_current) / 2
    turnover = round((exits / avg_hc * 100), 2) if avg_hc > 0 else 0

    climate = aval[aval["Survey_Type"] == "Climate"]
    total   = len(climate)
    prom    = (climate["eNPS_Score"] >= 9).sum()
    det     = (climate["eNPS_Score"] <= 6).sum()
    enps    = round(((prom - det) / total * 100), 2) if total > 0 else 0

    return pd.DataFrame([{
        "Date": today.date(), "HC_Current": hc_current,
        "Turnover_Pct": turnover, "eNPS": enps
    }])

# ── 3. LOAD ───────────────────────────────────────────────────
def save_results(df: pd.DataFrame, dest: str) -> None:
    df.to_excel(dest, index=False)
    print(f"KPIs saved to: {dest}")

if __name__ == "__main__":
    data = extract_data("workforce.xlsx")
    kpis = calculate_kpis(data)
    save_results(kpis, "kpis_people_analytics.xlsx")

SQL — Reference Queries for People Analytics

Consolidated monthly KPI view
CREATE VIEW vw_people_analytics_kpis AS
WITH
  hc_monthly AS (
    SELECT strftime('%Y-%m', Event_Date) AS year_month,
           COUNT(DISTINCT Employee_ID)   AS hc
    FROM fato_Historico
    WHERE Event_Type IN ('Hire','Active')
    GROUP BY 1
  ),
  exits_monthly AS (
    SELECT strftime('%Y-%m', Event_Date) AS year_month,
           COUNT(*)                       AS exits,
           SUM(CASE WHEN Reason = 'Voluntary' THEN 1 ELSE 0 END) AS vol_exits
    FROM fato_Historico
    WHERE Event_Type = 'Termination'
    GROUP BY 1
  ),
  enps_monthly AS (
    SELECT strftime('%Y-%m', Assessment_Date) AS year_month,
           ROUND(
             (SUM(CASE WHEN eNPS_Score >= 9 THEN 1.0 ELSE 0 END)
             -SUM(CASE WHEN eNPS_Score <= 6 THEN 1.0 ELSE 0 END))
             / COUNT(*) * 100, 2) AS enps
    FROM fato_Avaliacoes
    WHERE Survey_Type = 'Climate'
    GROUP BY 1
  )
SELECT h.year_month, h.hc AS headcount, s.exits,
       ROUND(s.exits * 100.0 / h.hc, 2)           AS turnover_pct,
       ROUND(s.vol_exits * 100.0 / h.hc, 2)       AS vol_turnover_pct,
       e.enps
FROM hc_monthly h
LEFT JOIN exits_monthly s ON h.year_month = s.year_month
LEFT JOIN enps_monthly  e ON h.year_month = e.year_month
ORDER BY h.year_month;
